# EBM Research Project

## Project Overview

This repository contains our completed group project for the **EBM course**.

The project investigates a business-related research question using both qualitative and quantitative research approaches. The final report was prepared in PowerPoint format and submitted as a PDF.

## Project Content

The project includes the following main parts:

- Title page with group information
- Executive summary
- Introduction and research question
- Theoretical background and literature review
- Qualitative research based on netnography
- Main qualitative findings
- Quantitative research proposal
- Hypotheses
- Proposed sample and procedure
- Expected findings and interpretation
- References
- Appendix materials

## Research Approach

The project is divided into two parts.

### Qualitative Part

We conducted netnographic research by observing a selected online field. Based on field notes and collected examples, we identified recurring themes and interpreted them using relevant theory.

### Quantitative Part

Based on the qualitative findings, we developed hypotheses and proposed a quantitative research design. This includes the target sample, sampling strategy, procedure, and possible measures.

## Deliverables

The completed project includes:

- Final PowerPoint report
- PDF version of the report
- References and in-text citations
- Tables and figures where applicable
- Appendix materials
- Notes and supporting materials
